# Cavi 每日埋点分析页设计

## 目标

交付一个可直接打开的独立单页 `cavi-analytics.html`，基于用户提供的 CSV 快照和飞书“自定义埋点”表生成每日分析报表。页面服务于两类日常查看：按 `Content Group` 汇总点击 UV 累计、按埋点点击率排序并支持模糊筛选。

## 已确认的统计口径

- 数据范围：CSV 中 2026-07-24 至 2026-08-06 的记录。
- `Event name=view_item` 视为曝光，`Event name=click` 视为点击。
- 所有 UV 按日期分别累计；跨日同一用户不做去重，因此页面明确标注“按日累计”。
- 来源排行：在选定日期内，仅取 `Event name=click`，按 `Content Group` 汇总 `Total users`，降序排列。
- 点击率排行：在选定日期内按 `element_name` 汇总点击与曝光，再计算 `click_uv / view_uv`。缺少曝光分母时显示“—”，不参与点击率排序。
- 中文名称映射：从飞书“自定义埋点”表 B 列读取。优先使用同一 `element_name` 且事件为 click 的行；若不存在则使用 view_item 行；页面同时展示英文 `element_name` 以便核对。
- 映射异常：`caviaix_entry_module_card` 在表中以历史拼写 `cavaiix_entry_module_card` 出现，但备注明确说明已改名；按备注中的新名称归一。其它无法映射的埋点保留英文名，不虚构中文名。

## 页面结构（B · 纵向报告）

1. 顶部品牌区：`CAVI ANALYTICS`、页面标题“交互数据日报”、数据范围和“按日累计”说明。
2. 控制区：日期下拉/原生日期选择器，默认选择最新日期；日期切换后两个分析模块同步刷新。
3. 来源点击模块：显示当日点击 UV 总量、来源数量，以及按点击 UV 降序的横向条形排行；条长相对于当日最大来源归一化。
4. 点击率模块：显示搜索框和结果数量；表格列为“埋点名称 / 点击率 / 点击 UV”，点击率列使用条形背景展示实际百分比（宽度上限为 100%，数值仍展示真实结果），并在名称下展示英文埋点名。
5. 空状态/异常状态：无数据日期显示空状态；无曝光分母的埋点显示“—”和“缺少曝光数据”，不显示为 0%。

## 数据流与实现边界

- 不在浏览器运行时请求飞书 API，避免权限、跨域和离线打开问题。
- 将 CSV 汇总结果和映射后的展示名称固化为内嵌 JSON，页面只负责筛选、排序和渲染。
- 原始 CSV 不写回、不修改；构建时保留源文件名、数据范围和生成时间作为页面元数据。
- 当前页面作为 `AutoCava-publish/cavi-analytics.html` 交付，不改动现有 `index.html` 和 Nuxt 静态资源。

## 交互细节

- 日期选择器只允许选择数据中存在的日期；切换后滚动位置保持在页面顶部。
- 搜索框对中文名称和英文 `element_name` 做不区分大小写的包含匹配。
- 点击率排序固定为降序；同率时按点击 UV 降序，再按埋点名称字典序。
- 来源排行不受埋点搜索框影响。
- 数字使用千分位；点击率保留 1 位小数，原始比率不做四舍五入参与排序。

## 验证计划

- 用脚本对每个日期分别核对来源点击累计、点击/曝光汇总和排序结果。
- 校验全周期内 14 个同时存在 click/view_item 的埋点，并逐日核对实际可计算项；缺曝光埋点数量与页面“—”数量一致。
- 校验中文映射覆盖率、历史拼写归一逻辑和无法映射项的英文兜底。
- 在桌面宽度、窄屏宽度各进行一次视觉检查，确认表头、条形背景、日期控件和空状态不被截断。
- 用浏览器手动验证日期切换、模糊搜索、无结果状态和清除搜索行为。
