# Cavi 特殊点击率分母设计

## 目标

在现有 `cavi-analytics.html` 点击率报表中，为 4 个埋点使用指定的跨埋点曝光分母，同时保留其它埋点“自身点击 UV ÷ 自身曝光 UV”的默认口径。日期筛选、排序和模糊搜索行为保持不变。

## 统计口径

所有分子与分母均在用户选择的闭区间日期内按日累计，不进行跨日用户去重。

| 点击埋点 | 曝光分母埋点 |
|---|---|
| `caviaix_session_layer_close` | `caviaix_session_layer` |
| `caviaix_session_layer_input_box` | `caviaix_session_layer` |
| `caviaix_dislike_layer_option_btn` | `caviaix_likeorno_layer_option_btn` |
| `caviaix_like_layer_option_btn` | `caviaix_likeorno_layer_option_btn` |

计算规则：

- 上表中的点击埋点：自身 `click` 事件的 `Total users` 累计值 ÷ 对应分母埋点 `view_item` 事件的 `Total users` 累计值。
- 其它埋点：自身 `click` 事件的 `Total users` 累计值 ÷ 自身 `view_item` 事件的 `Total users` 累计值。
- 指定分母没有曝光时点击率显示“—”，不按 0% 处理。
- 点击率排序仍使用未四舍五入的原始比率；展示值保留 1 位小数。

## 实现设计

在构建脚本中定义一份声明式 `CTR_DENOMINATOR_OVERRIDES` 映射，作为特殊口径的唯一配置源。构建时将该映射写入页面内嵌 JSON，Python 区间聚合与浏览器日期区间聚合都读取这份配置，避免两端分别硬编码。

每日数据仍保存每个 `element_name` 自身的点击 UV 和曝光 UV。区间聚合完成后，再为每个点击埋点解析有效分母：优先取特殊映射，否则取自身。最终结果保留：

- `click_uv`：点击埋点自身的点击累计值；
- `view_uv`：实际分母埋点的曝光累计值；
- `denominator_element`：实际分母埋点英文名；
- `ctr`：`click_uv / view_uv`，分母为 0 时为缺失值。

## 页面展示

- 点击率表结构保持“埋点名称 / 点击率 / 点击 UV”。
- 点击率单元格悬停提示显示完整公式、实际分母埋点英文名和曝光 UV。
- 点击率模块下增加特殊口径说明，列出 4 条跨埋点分母规则。
- 普通埋点的提示仍说明使用自身曝光 UV。
- 模糊筛选仍仅匹配展示埋点的中英文名称，不把分母名称加入搜索范围。

## 异常与边界

- 分母埋点在所选日期范围内不存在时，点击率显示“—”，提示缺少该指定分母的 `view_item` 数据。
- 分母埋点存在但曝光累计为 0 时，按缺失分母处理。
- 特殊点击埋点自身的 `view_item` 数据不参与其点击率计算。
- 仅有曝光、没有点击的埋点继续保留在每日聚合数据中，以便作为其它埋点的分母；点击率表仍只展示所选区间内点击 UV 大于 0 的埋点。

## 验证计划

- 单元测试分别覆盖默认自身分母、`session_layer` 共享分母和 `likeorno` 共享分母。
- 单元测试覆盖特殊点击埋点自身存在曝光但必须忽略的情况。
- 单元测试覆盖日期区间外的分子与分母均不进入计算。
- 静态页面检查确认内嵌特殊映射、页面口径说明和浏览器聚合逻辑存在。
- 重新生成 HTML 后，使用原始 CSV 独立计算 4 个特殊点击率，并与页面内嵌数据逐项对账。
